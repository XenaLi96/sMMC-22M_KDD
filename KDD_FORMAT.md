# KDD Datasets & Benchmarks formatting

This project uses the ACM `sigconf` review format required by the KDD
Datasets & Benchmarks Track:

```latex
\documentclass[sigconf,review]{acmart}
```

The track is single-blind, so complete author names and affiliations must be
added before submission. The current source intentionally keeps the original
empty author block because the imported manuscript did not contain author
metadata.

The ACM style files in this repository are from the official `acmart` 2.19
release distributed through CTAN:

- `acmart.cls`
- `ACM-Reference-Format.bst`

The main paper is followed by ACM-formatted references and then the original
appendix in the same PDF.

Official guidance:

- https://kdd2026.kdd.org/datasets-and-benchmarks-track-call-for-papers/
- https://ctan.org/pkg/acmart
